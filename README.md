# Novochronos

> **2026 NASA Space Apps Challenge**  
> **Challenge:** Abandoned but not Forgotten: Storytelling about NASA's Discarded Equipment on the Moon and Mars

## Project Scaffold Structure

```
Novochronos/
├── public/
│   └── audio/              # Narration audio files
├── scripts/                # Generation scripts (e.g. TTS)
└── src/
    ├── components/
    │   ├── canvas/         # 3D canvas and podium stages
    │   └── ui/             # Plaque, HUD, audio controls
    ├── data/               # Relic narratives, coordinates, specs
    ├── hooks/              # Scroll and stage hooks
    ├── services/           # NASA APIs and dataset clients
    ├── types/              # Type definitions
    ├── App.tsx             # Main entry component
    ├── index.css           # Global styling
    └── main.tsx            # DOM root
```

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Start dev server
npm run dev

# 3. Build project
npm run build
```
